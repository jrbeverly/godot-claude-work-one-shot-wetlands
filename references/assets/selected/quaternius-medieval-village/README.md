Timber/plaster walls, chunky tiled roofs, stone foundations, chimneys, fences and wagons for human-village references.

## Notes

- Selected glTF files include all external buffers and images; original scales and materials are unchanged.
- PNG textures are capped at 1024 px; full-resolution originals remain in the local downloaded archive.
- CC0 notice is retained in `LICENSE.txt`; exact source files and hashes are in `selection.json`.
- Godot 4.5.1 imported and rendered these models; preview sheets normalize each model size, not its world scale.
