Sixteen chunky tree, bare-tree, bush, grass and rock variants sharing one atlas for readable distant forest silhouettes.

## Notes

- CC0; Kay Lousberg notice retained. One colourway and one format only.
- Selected assets preserve original scale, materials and texture resolution; paths and hashes are in `selection.json`.
- Godot 4.5.1 imported and rendered these models; preview sheets normalize each model size, not its world scale.
